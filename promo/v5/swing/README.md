# WIREFRAMECH 鋼弦機兵：「鋼索機動戰」第三人稱實機鏡頭（promo v5 素材）

主題：**在地形之間連續甩鋼索、一邊擺盪一邊開火**。自機從空島邊緣跳出去，用鋼索掛上浮游岩甩出，再勾樹頂繞樹擺盪，擺盪途中用 57mm 和機槍攻擊；敵機也一直掛在鋼索上移動。最後在空島邊緣近距離把敵機擊破，然後飛出島緣。

- 鏡頭：**遊戲本身的第三人稱追尾鏡頭**（設定 → 鏡頭 → 第三人稱，電腦版 V 鍵，同一個 `setView(true)`）＋遊戲本身的 HUD。**全片沒有用宣傳用的自由鏡頭**（`H.cam`／`__camOverride`），也沒有加環繞鏡頭。
- 遊戲版本：`claude/modest-ramanujan-ob1zy7` 分支 `index.html`，commit **64be093**，以 `?promo=1` 執行。地圖是預設的「新手地圖」（大島＋兩座基地空島＋浮游岩），用的是西半邊（基地 A、浮游岩 (48,42,0)、樹林）。
- 規格：1920×1080、60 fps、H.264，長 **6.22 秒**（373 格，其中 8 格是 hit-stop）。
- 錄影方式：無頭 Chromium（軟體算圖），固定時間步長逐格推進、逐格截圖，再用 ffmpeg 編碼。

## 誠實說明：哪些是實際操作，哪些是擺拍或後製

**實際操作（玩家做得到的事）**
- 所有移動都是遊戲本身的物理：起跳、鋼索發射（遊戲的 `findHook` 射線，準星方向＋左右索各 ±8° 偏角）、W 收索、Shift 推進、放索後的慣性。腳本只像玩家一樣改滑鼠視角和按鍵。
- 三次勾點都是遊戲射線實際打到的可勾物件：浮游岩底部、兩棵松樹的樹冠頂部。腳本沒有硬塞錨點（沒有用 `H.hook`）。
- 兩次鋼索中斷是**遊戲自己切斷**的（索線被地形擋住時遊戲會斷索），不是腳本放開的。
- 鏡頭是遊戲的第三人稱追尾鏡頭；HUD 全是遊戲本身的。
- 三發 57mm 都是遊戲的砲彈、射控輔助、傷害判定：#1 爆風 436、#2 直擊 1500、#3 直擊 1500 擊破。機槍有實際開火，但沒有命中。
- 敵機機槍是遊戲的同一套武器程式。全片**自機被打中 0 發**（錄影時有記錄）。
- 擊破判定、爆炸、擊破卡片、比分都是遊戲本身的。

**擺拍／輔助（請剪輯和文案注意）**
1. **起始位置是擺的**：自機放在基地 A 空島東緣；敵機放在空中 (80, 24, 16)，第一格就射出鋼索（開錄前 6 格），所以開場敵機已經「掛在鋼索上擺盪」。
2. **敵機血量是預設的：3400/6000**（像是之前已經受過傷）。遊戲裡 57mm 直擊 1500，滿血敵機需要 4 發；這段只打中兩發直擊＋一發爆風就擊破，是因為血量預設過。
3. **敵機由腳本操控**（`?promo=1` 的 `__botCmd`，和遊戲 AI 用的是同一個指令格式）：右鋼索射向附近的樹頂、低於 26 m 就收索／推進維持高度；鋼索被遊戲切斷後，就射向下一棵還沒用過的樹（全片敵機換了 3 次鋼索）。遊戲內建 AI 本身也會用右鋼索（智慧勾索）跨島移動，但它不會這樣在樹頂之間連續擺盪，**這是為宣傳片寫的敵機行為**。敵機瞄準「自機 14 格前的位置再往後偏 5 m」，刻意讓子彈從後面擦過。
4. **自機血量鎖在 4380**：只是 HUD 數字（實際沒被打中）。
5. **擊破後的處理**：遊戲在擊破時會把敵機傳送回它的基地重生。腳本把重生後的模型藏起來，並在擊破點多加兩次 `__promoBurst` 火花（宣傳模式才有），爆炸比一般遊玩大一點。**但 HUD 上的敵機名牌和紅色鎖定菱形仍然會指向遠處重生的敵機**（畫面右上的「Kestrel_09」小名牌、準星旁「316m」），見已知問題。
6. **變速（0.3 倍）**是錄影腳本調慢遊戲時鐘，實際遊玩不會變慢。
7. 比分預設 2:1、倒數 2:11；自機副武器選機槍（`wfm.s2 = mg`，是遊戲的正常配裝選項）。

**後製（`post_sw.py`，只在宣傳片裡）**
- 擊破：hit-stop 8 格、推近 9%、震動。前兩發 57mm 命中時有輕微推近和震動（不停格）。
- **曳光彈光暈**：遊戲的曳光彈是 1 像素細線；錄影時記下每格遊戲曳光線（顏色 0xffe08a 的線，只有曳光彈用這個顏色）的螢幕座標，後製沿同一條線疊暖黃色光暈。**請標成後製效果。**
- 字幕、9:16 重新構圖。

## 9:16 直式版

- 從 1920×1080 裁出 608×1080（裁切框中心 x=1030，略偏右，因為敵機多半在自機右側）再放大到 1080×1920。
- 左上自機資訊窗從同一格剪下、放大 1.5 倍貼回；擊破卡片出現時從同一格剪下放大 1.6 倍貼到右上。比分條和中央準星本來就在裁切範圍內。
- 字幕在 HUD 資訊窗下方（約 19% 高度）。

## 已知問題

- **敵機在中段偏小**：1.0–3.0 秒敵機在 45–55 m 外，只看得到 HUD 的紅色菱形、名牌和血條，機體本身很小，有時被中央準星圈蓋住。近距離最清楚的是 3.9–4.3 秒。
- 敵機的鋼索在遠距離很細；最明顯的是 4.0 秒（關鍵格 2）那條發光的索。
- 擊破後 HUD 的敵機名牌和鎖定菱形會指向遠處重生點（約 300 m 外），畫面上是很小的標記。
- 機槍那一段沒有命中標記。
- 「中段 apex 變速」只做在最後一發 57mm（近距離交錯）那一段，其他擺盪頂點沒有變速。
- 依要求可以加的「宣傳用環繞鏡頭」這版沒有加，全片都是遊戲鏡頭。
- 長度 6.22 秒；需要更長可用 `--hold` 加長 hit-stop，或把 `FRAMES` 加大（自機之後會一路往下掉進虛空，約到第 340 格以後高度就很低了）。
- 物理是 1/120 秒步長，變速段有些格只有插值，逐格看會有少數格幾乎重複。

## 如何重新錄製

需要 Node＋Playwright（`require('playwright')`，不要跑 `playwright install`）、Python 3＋Pillow、ffmpeg。不需要本機伺服器（攔截請求直接讀檔）。

```bash
# 1) 遊戲檔（不要動 /home/user/Wireframech）
git -C <clone> fetch origin claude/modest-ramanujan-ob1zy7
mkdir -p <game>/assets && git -C <clone> show FETCH_HEAD:index.html > <game>/index.html
for f in assets/ground.jpg assets/mech.glb assets/pine.glb; do git -C <clone> show FETCH_HEAD:$f > <game>/$f; done

# 2) 乾跑（不算圖，只印位置／鋼索／血量／開砲，一次比較多組參數；約 1–2 分鐘）
GAMEDIR=<game> CDN_CACHE=<cdn> LAB=lab_sw.js VARS='[{},{"h3":176}]' EVERY=6 node cap_sw.js base.js x

# 3) 只截幾格看構圖
KEYS=50,240,262 FRAMES=270 GAMEDIR=<game> CDN_CACHE=<cdn> node cap_sw.js choreo_sw.js <dir> 1000

# 4) 正式逐格錄影（365 格，約 25 分鐘）
GAMEDIR=<game> CDN_CACHE=<cdn> node cap_sw.js choreo_sw.js <frames> 1

# 5) 後製
python3 post_sw.py <frames> swing_combat.mp4 --end 365 --hold 8 --impact 257 --crf 24
python3 post_sw.py <frames> swing_combat_caption.mp4 --end 365 --hold 8 --impact 257 --crf 24 --caption
python3 post_sw.py <frames> swing_combat_9x16.mp4 --end 365 --hold 8 --impact 257 --crf 22 --caption --vertical
python3 sheet_sw.py <frames> swing_combat_contact.png 0,30,50,...  4 "標籤1|標籤2|..."
```

### 腳本

| 檔案 | 用途 |
|---|---|
| `cap_sw.js` | 錄影主程式（從 `promo_v5_tp/cap_tp.js` 複製）：攔截請求、假時鐘逐格推進、固定亂數、截圖、輸出 `probe.json`。新增 `EVAL=檔案` 模式（載入遊戲後執行一段程式並印出結果，用來探勘地圖）、乾跑也會跑開錄前的格數 |
| `base.js` | 共用設定（PC、繁中、副武器機槍） |
| `h_init.js` | 宣傳片輔助 `H`（原樣複製） |
| `sw_helpers.js` | 視角／第三人稱瞄準輔助（從 `tp_helpers.js` 複製，probe 多記錄敵機鋼索） |
| `choreo_sw.js` | **分鏡腳本**。參數在 `CFG`：起點 `P0`、三個勾點 `R1/R2/R3` 和左右索 `c1/c2/c3`、勾索格 `h2/h3`、收索／推進格 `reel2/b2`、57mm 開火時段 `shots`、機槍時段 `mg`、敵機起點 `E0/EV`、敵機維持高度 `eAlt`、可勾的樹 `trees`、敵機血量 `ehp`、變速 `slowK/slowIn/slowHold/slowOut`。可用環境變數 `CFG='{...}'` 覆寫 |
| `lab_sw.js` | 乾跑多組參數 |
| `post_sw.py` | 後製與編碼 |
| `sheet_sw.py` | 縮圖表 |

注意：這個場景對參數很敏感（勾點差一點，鋼索斷的時間就不同，後面整段路線都會變）。改任何參數後請先乾跑，確認 `sh`（開砲格）、`dead`（擊破格）、血量變化，再正式錄。
